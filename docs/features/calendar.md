# Calendar

Bulwark includes an integrated calendar powered by JMAP Calendars (JSCalendar).

## Views

- **Month view** — Overview of the entire month
- **Week view** — Detailed weekly schedule
- **Day view** — Hour-by-hour daily agenda
- **Agenda view** — Chronological list of upcoming events

## Creating Events

Click on any time slot or use the "New Event" button to create an event:

- Title and description
- Start and end time with timezone support
- All-day events
- Location (with map link support)
- Recurrence rules (daily, weekly, monthly, yearly)
- Reminders and alerts

## Sharing & Invitations

- Send calendar invitations via email
- Accept/decline/tentative responses
- Shared calendars with other Stalwart users
- CalDAV compatibility through Stalwart

## Multiple Calendars

Create and manage multiple calendars with different colors. Toggle visibility of individual calendars to focus on what matters.
