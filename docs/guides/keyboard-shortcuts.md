# Keyboard Shortcuts

Bulwark supports keyboard shortcuts for power users. Press `?` anywhere in the app to show the shortcuts overlay.

## Global

| Shortcut | Action                   |
| -------- | ------------------------ |
| `C`      | Compose new email        |
| `?`      | Show keyboard shortcuts  |
| `/`      | Focus search             |
| `Esc`    | Close overlay / deselect |

## Navigation

| Shortcut     | Action         |
| ------------ | -------------- |
| `G` then `I` | Go to Inbox    |
| `G` then `S` | Go to Sent     |
| `G` then `D` | Go to Drafts   |
| `G` then `T` | Go to Trash    |
| `G` then `A` | Go to Archive  |
| `G` then `C` | Go to Calendar |
| `G` then `O` | Go to Contacts |

## Email List

| Shortcut  | Action                |
| --------- | --------------------- |
| `J` / `↓` | Next email            |
| `K` / `↑` | Previous email        |
| `Enter`   | Open email            |
| `X`       | Select/deselect email |
| `E`       | Archive               |
| `#`       | Delete                |
| `!`       | Mark as spam          |
| `U`       | Mark as unread        |

## Reading Email

| Shortcut | Action    |
| -------- | --------- |
| `R`      | Reply     |
| `A`      | Reply all |
| `F`      | Forward   |
| `E`      | Archive   |
| `#`      | Delete    |
